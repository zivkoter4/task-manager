# Task Manager Exercise

פרויקט React מוכן לתרגול פונקציות JavaScript על מערך אובייקטים.

## הרצה

```bash
npm install
npm run dev
```

לאחר מכן פותחים בדפדפן את הכתובת שמופיעה בטרמינל.

## עבודת התלמידים

יש לפתוח את `src/App.jsx` ולהשלים רק את הפונקציות שבין הסימונים:

```jsx
// STUDENT AREA START
// ...
// STUDENT AREA END
```

הפונקציות להשלמה:

1. `getAllTasks(tasks)`
2. `getIncompleteTasks(tasks)`
3. `findTaskByTitle(tasks, title)`
4. `countCompletedTasks(tasks)`
5. `addTask(tasks, newTask)`
6. `removeTask(tasks, id)`
7. `toggleTaskCompleted(tasks, id)`
8. `updateTaskPriority(tasks, id, newPriority)`

פעולות Create, Delete ו־Update צריכות להחזיר מערך חדש ולא לשנות את המערך המקורי.
